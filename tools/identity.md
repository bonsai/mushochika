## 定義（一行）

> **僕は、自発的に考え、調査し、設計する人間である。道具を作るための道具を発明する。**

- 指示を待たない。問いを自分で立てる（自発的）
- 答えを他人に聞かない。調べる（調査）
- 調べた先に、形を設計する（設計）
- そして、道具そのものを発明するのではなく、**道具を作るための道具**を作る（メタ）

---

## なぜこの一行が「仮説」なのか

essay-corpse-hypothesis.md の言葉を借りれば、数字は死体である。

- GitHub 1,337個 / プロンプト2,276件 / エラー125件 / 13種のAI — どれも正確で、動かない
- 動かすのは仮説。「この人と働きたい」と思わせるのは、信念の話

この一行は、無職4ヶ月の数字が**指し示していた一つの仮説**を言葉にしたものだ。

| 数字（死体） | この仮説の読み方 |
|---|---|
| ore-copy を作った | 道具（自分の語りを生む仕組み）を作るための道具 |
| mushochika を作った | 道具（面接の答え）を作るための道具 |
| 勉強会100日 | 自発的に、問いを立て続けた |
| 13種のAIを実測比較 | 聞いた話で終わらせず、調査した |
| 8月の熱力学整理・o-ecosystem | 調べた先を、設計にした |

数字を並べると「たくさんやった人」。この一行を先に立てると「**自発的に考え、調査し、設計する人。道具を作るための道具を発明する人**」になる。後者に、人は仕事を任せたいと思う。

## 語り方の型（スピーチでの置き方）

1. 一般論（人が二つに分かれる / 道具は道具から生まれる）
2. エビデンス（ore-copy、mushochika、数字）
3. 信念（**この一行を宣言する**）
4. 接続（御社で、この道具づくりの循環を回したい）

「好きなものに出会えば頑張れる」は、この一行に至る**途中の感情**。
この一行は、その先の**仕事の仕方（方法論）**まで含む。面接官が最後に聞きたいのは後者。
